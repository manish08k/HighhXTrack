# HighhxTracker

**A centralized personal management application for productivity, fitness, finances, habits, and everyday planning.**

HighhxTracker is a personal productivity application designed to help users organize their daily activities and manage important aspects of their lives from one place. It brings task management, workout tracking, expense management, reminders, habit tracking, calendar planning, document management, notes, and study tracking together in a single application.

The goal is to simplify everyday organization, improve consistency, and help users keep track of their personal goals and responsibilities.

## Features

### Task Management
- Create and organize daily tasks.
- Set task priorities and categories.
- Manage recurring tasks and subtasks.
- Track task completion and progress.

### Gym and Workout Tracking
- Record exercises, sets, repetitions, and weights.
- Maintain workout history.
- Track personal records and body measurements.
- Monitor workout progress.

### Expense and Money Management
- Record income and expenses.
- Organize transactions by category.
- Track monthly budgets and savings.
- Monitor personal spending.

### Reminders
- Create one-time reminders.
- Schedule recurring reminders.
- Keep track of important activities and deadlines.

### Habit Tracking
- Track daily habits.
- Maintain completion streaks.
- Review consistency and progress over time.

### Calendar
- Organize events, tasks, workouts, and reminders.
- View scheduled activities in one place.
- Plan daily and upcoming activities.

### Document and Expiry Tracking
- Keep records of important documents.
- Track passports, licenses, insurance policies, and certificates.
- Monitor expiry dates and plan renewals.

### Notes Management
- Create and manage quick notes.
- Organize notes using folders and tags.
- Keep important information accessible.

### Study Tracker
- Organize study activities.
- Track learning routines and progress.
- Maintain a structured approach to studying.

## Project Goals

HighhxTracker aims to provide a practical, centralized solution for managing personal responsibilities without relying on multiple separate tracking applications.

The project focuses on usability, organization, consistency, and making everyday tracking easier.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or another compatible development environment
- Android device or emulator for testing

### Run Locally

Clone the repository:

```bash
git clone https://github.com/manish08k/HighhXTrack.git
```

Navigate to the project directory:

```bash
cd HighhXTrack
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
